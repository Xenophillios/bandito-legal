2. Zweck der Anwendung

Der Bandito Clip Editor ist eine nichtkommerzielle Discord-Anwendung zur Wiedergabe und Bearbeitung von Audioclips.

Die Anwendung ist für die private Discord-Community Bandito Saloon vorgesehen und wird zusammen mit dem Discord-Bot Hottest Bandito verwendet.

Die Nutzung der Anwendung ist kostenlos.

Für den Zugriff auf geschützte Funktionen ist eine erfolgreiche Discord-Authentifizierung erforderlich.

Der Zugang kann bei Missbrauch, unberechtigter Verwendung oder Verstößen gegen die geltenden Serverregeln eingeschränkt werden.

5. Bearbeitung von Audioclips

Berechtigte Mitglieder können veröffentlichte Clips innerhalb der vorgesehenen Funktionen bearbeiten.

Dazu gehören insbesondere:

  • Das zeitliche Zuschneiden von Clips
  • Die Auswahl einzelner Audiospuren
  • Das Anhören einer Audiovorschau
  • Das Speichern einer bearbeiteten Version

Bearbeitungen können die Audiodatei der bestehenden Discord-Clip-Nachricht verändern.

Andere berechtigte Mitglieder können denselben Clip ebenfalls bearbeiten. Deshalb kann eine bereits bearbeitete Version später erneut verändert werden.
